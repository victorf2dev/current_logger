# current_logger
Logger for DC electrical current consumption

## Serial port

baudrate: 9600

## Data format

`bus_voltage:12.24, load_voltage:12.24, shunt_voltage:0.32, current:6.22, power:36.00`

bus_voltage:    12.24 V
load_voltage:   12.24 V
shunt_voltage:  0.32 mV
current:        6.22 mA
power:          36.00 mW
